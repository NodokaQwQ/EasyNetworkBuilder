# Head 0.0.5

仅发布 Head（Linux/amd64），Node 维持 0.0.1；不自动部署线上服务、不移动 latest。仅开放经隔离验收的 0.0.4 → 0.0.5。

## 改动

- 回程监测按服务器管理多个目标，各目标独立配置运营商与预期线路，自动关联 ICMP 延迟/丢包监测；间隔默认跟随回程，也可更短。旧任务启动时幂等补齐，手工监测不接管。
- 节点列表操作栏可打开该服务器的基础计费配置和完整计费操作。复用详情页逻辑，保留到期时区、续费匹配和费用幂等键；流量额度更新失败明确提示，窗口内重试不重复记账。
- 新增 ENB Material You 公共主题，更新管理界面、Material Symbols、图表配色和多时间粒度流量/延迟图表。
- 修复多日流量图校准跨日误用问题；按各自日期应用额外量，负校准不扣减其他日期。
- 修复新主题测试入口，并从历史记录补齐 0.0.2 发布清单缺失的来源版本与发布时间，保持旧镜像身份不变。

## 验证和边界

- Head 全仓 `go test -race -count=1 -timeout=12m ./...`（含 GeoIP）及 `go vet ./...`、管理前端 787 项测试/生产构建/ESLint（仅警告）、公共主题 5 项测试/生产构建、发布目录和更新器单元测试通过。
- Head 镜像首启安装门禁、嵌入前端、匿名拒绝、EasyTier CLI 和重启次数检查通过。隔离真实 Compose 从已初始化的 0.0.4 升级到 0.0.5，验证版本/hash/数据库就绪、原节点配置和回程任务 ID、托管监测启动补齐；注入目标健康失败后恢复旧镜像与停机数据快照。仅 registry pull 替换为已构建本地镜像，发布时另行核对远端 digest。
- 镜像内真实登录 API 验证多目标保存、重复目标拒绝且原数据不变、任务/托管监测删除、三类费用重复提交幂等、额度修改、到期时区保留和匿名写请求拒绝。8 并发共 64 次版本读取通过，仅为小规模并发冒烟，不代表容量压测。
- 扩展源码检查修复 Node Xray 在监听后替换处理器及逐连接重写全局拨号器的竞态，并修正恢复任务测试自身的配置并发访问。**Node 仍发布 0.0.1，以上源码修复不包含在既有 Node 镜像中**；后续须独立发布 Node 才能交付。
- Node 使用正式构建标签 `with_quic,with_utls` 的非防火墙全仓竞态测试及全仓 vet 通过；防火墙全包竞态测试在独立 mount/net 命名空间、虚拟双栈网卡、临时数据及隐藏宿主规则目录的环境下通过，无跳过项。

- 计费与额度仍是两个独立请求，非后端原子事务；关闭失败窗口后应单独编辑额度，不应再次记账。
- 双栈域名的现有 Node 延迟探测使用 DNS 首地址，而回程使用指定地址族；严格对照请填写具体 IP。本版本不改变 Node 协议。
- 不承诺完整代理业务、跨设备 SSH 镜像中转、所有主题和移动端布局已端到端验收；此前发布说明中的其他限制继续适用。
