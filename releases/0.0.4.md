# Head 0.0.4

仅发布 Head，Node 保持 0.0.1；由管理员在 Web 面板手动更新，不自动修改线上容器、MY 备用代理或 latest 标签。

## 改动

- 虚拟内网的部署设置可保存已有 EasyTier RPC 地址和可选实例名；主控 HTTPS 地址、虚拟 IP、设备 SSH 与权限继续由现有面板入口管理。宿主机 CLI、持久数据、更新器路径仍由管理员在可信配置中设置，网页不开放任意路径执行。
- 新 Node 安装从官方稳定版发布目录选择兼容版本并固定 digest；镜像本地检查、限时拉取，失败后可使用已授权设备经 SSH 流式中转。镜像身份验证失败则停止，不在获取镜像失败时触碰目标 Node 数据。
- README 和示例改为通用部署说明，去掉当前个人部署记录；保留官方镜像仓库与 Git 发布源。修正图表日期在不同时区显示错误，通用化测试节点名。
- 保留 Head 0.0.3 的 Reality MLKEM 订阅生成修复。

## 验证和边界

- Head 全仓 Go 测试、相关竞态测试、vet、前端测试/构建、版本目录及宿主更新器单元测试、镜像启动验证通过。发布目录允许 0.0.3 → 0.0.4；是否允许 0.0.2 直接升级须单独验证，不在此目录中开放。
- 动态 Node 镜像选择和 SSH 中转通过单元测试，**尚未进行真实跨节点流式传输验收**；原有完整 Mihomo 订阅连接问题也尚未独立验收。本发布不保证这两项功能的端到端可用性。
- 当前文件去个人化不等于历史提交已清除；仓库历史可能留有早期部署说明。许可证与上游归属见各组件声明及 UPSTREAM.md，统一许可证审查尚未完成。
