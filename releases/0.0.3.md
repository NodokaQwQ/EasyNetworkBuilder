# Head 0.0.3

仅发布 Head，Node 保持 0.0.1；不自动更新线上容器，不移动 latest。

## 修复

- 为 ENB 管理的 Reality 节点生成 Mihomo 配置时，显式启用 `reality-opts.support-x25519mlkem768: true`，避免默认关闭 MLKEM 导致新版 Xray Reality 拒绝握手。
- 同步修复旧 Clash 格式订阅与 VLESS 分享链接中的 MLKEM 提示，保留原地址、UUID、Reality 密钥和分流设置。

## 验证与限制

- 订阅生成器、模板及 HTTP 订阅测试通过，覆盖 Mihomo YAML、旧 Clash YAML、分享链接和普通 TLS 不添加 Reality 选项。
- MLKEM 开关的 Mihomo 实测曾确认关闭失败、开启成功，但当前完整订阅的真实连接仍有 Reality 认证失败待排查。本版本修复已确认的生成器漏项，不宣称完整业务兼容性验收通过。
- 无数据库结构变更；允许从 Head 0.0.2 手动更新，支持停机数据快照回退。MY 备用代理不在此版本操作范围内。
