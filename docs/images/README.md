## 来源与脱敏方式

- 使用本地前端构建产物渲染实际界面，在隔离预览中注入虚构 HTTP / JSON-RPC / WebSocket 响应，不连接真实 Head、Node、EasyTier RPC 或 SSH。
- 设备名、用户、节点 ID、费用、流量、延迟和在线状态均为演示值；没有导出生产响应、保存运行数据库或使用真实密钥。
- IPv4 使用文档保留段 `192.0.2.0/24`，IPv6 使用 `2001:db8::/32`，域名使用 `head.example.com`。这些地址不是可用的组网或部署配置。
- 图片右下角标注 `ENB SOURCE PREVIEW · 虚构演示数据`。后台的 HTTP 安全警告是本地回环预览的实际提示；正式部署仍须使用 HTTPS。
- 图片展示源码界面，不能证明稳定镜像具有完全相同的外观，也不证明截图中的部署、凭据、权限或代理连接已经真实验证。

后续更新截图时应继续使用虚构数据，不要仅靠遮住密码框掩盖真实设备名、IP、订阅地址或浏览器个人信息。
